# Data Science Assignment 500

## Description
This assignment is a Python data science assignment using web scraping, data cleaning, visualisation and predictive modelling.

## Files
* assignment.ipynb: Contains the code and results.
* books.csv: The cleaned dataset used for analysis.

## Requirements
Inside the terminal:

pip install numpy pandas requests beautifulsoup4 matplotlib scikit-learn

## How to run:
1. Install the required libraries.
2. Open the Jupyter Notebook.
3. Run the cells in order.
